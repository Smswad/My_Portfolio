# Personal Portfolio Project Specification

## Overview

Build a polished, fully responsive, and professional personal portfolio website to showcase your skills, educational background, professional experience, and key projects.

> **Technology Stack:** You can use any modern technology stack (e.g., React, Next.js, Vue, Tailwind CSS, or Vanilla HTML/CSS/JS). All stated requirements must be met.

---

## Task Requirements

### 1. Navigation Bar (Navbar)
* **Responsiveness:** Fully responsive across mobile, tablet, laptop, and desktop screens.
* **Accessibility:** Provides smooth scrolling and direct, intuitive access to every key section of the portfolio.

### 2. Designation & Introduction (Hero Section)
* **Professional Title:** Prominently display your designation (e.g., *Frontend Developer*, *Web Developer*, *Full Stack Developer*).
* **Profile Image:** Include a high-quality, professional photograph of yourself.
* **Brief Introduction:** A concise, impactful opening statement introducing who you are.

### 3. Resume Download Button
* **Placement:** Positioned prominently within the hero section.
* **Functionality:** 
  * A single-click button allowing visitors to view and download your resume.
  * *Note:* If your resume file is not finalized, provide a clickable button placeholder configured for an upcoming download link.

### 4. Social Links
* Embedded interactive links/icons directing to your professional profiles:
  * GitHub
  * LinkedIn
  * Twitter / X
  * Facebook / other relevant platforms

### 5. About Me Section
A comprehensive personal overview showcasing both technical background and personality:
* **Journey:** Your story and path into programming and software development.
* **Interests:** The specific domains, architectures, and types of projects you enjoy building.
* **Beyond the Code:** Personal hobbies and activities outside of development (e.g., sports, reading, painting, music).

### 6. Skills Section
* **Visual Presentation:** Display your competencies in a visually engaging graphical format (e.g., progress indicators, skill badges, or animated cards).
* **Categorization:** Group skills logically into categories:
  * **Frontend:** (e.g., HTML5, CSS3, JavaScript, React, Tailwind CSS)
  * **Backend:** (e.g., Node.js, Express, MongoDB)
  * **Tools & Platforms:** (e.g., Git, GitHub, VS Code, Figma, Vercel)

### 7. Educational Qualification
* Detailed academic history for any degree or diploma completed beyond Higher Secondary Certificate (HSC) / high school level.
* Include institution name, degree title, major/field of study, and graduation year/status.

### 8. Professional Experience *(If Applicable)*
* Highlight relevant work experience, internships, or freelance engagements:
  * Role title and company/organization name
  * Period of employment
  * Key responsibilities and measurable achievements

### 9. Projects Section *(Minimum 3 Projects)*
Showcase at least three of your top projects in an organized card layout.

#### Project Card Elements:
* Project thumbnail/image
* Project title
* "View More / Details" action button

#### Dedicated Project Details Modal / Page:
Clicking the "View More / Details" button must display:
* **Tech Stack:** Primary programming languages, libraries, and frameworks used.
* **Description:** Comprehensive overview of the project scope and core functionality.
* **Links:**
  * Live deployed application link
  * GitHub repository link (client-side repository)
* **Challenges Faced:** Key technical obstacles encountered during development and how you solved them.
* **Future Improvements:** Planned features and architectural enhancements for future versions.

### 10. Contact Information
Direct communication channels for recruiters and collaborators:
* Email address
* Phone number
* WhatsApp contact link *(optional)*
* Optional contact form for direct inquiries

### 11. Footer *(Optional)*
* A clean, modern footer containing quick navigation, copyright details, and social icons.

### 12. Design & Responsive UI
* **Device Support:** Flawless layout across all screen widths (desktop, laptop, tablet, mobile).
* **Aesthetics:** Cohesive, professional typography and color scheme with proper contrast.
